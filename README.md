## 📌 Project Overview
A simple, clean frontend web directory built using **only HTML and CSS** based on **Unit #1, Unit #2, and Unit #3** of the CSE326 curriculum. There is **no JavaScript used**.

---

## 📋 Syllabus Topics Demonstrated

### 1. Unit #1: HTML Fundamentals
* **Tags & Elements:** Headings (`<h1>` to `<h3>`), Paragraphs (`<p>`), Horizontal Rule (`<hr>`).
* **Text Formatting:** Bold (`<strong>`), Subscript (`<sub>`), Superscript (`<sup>`).
* **Lists:** Unordered List (`<ul>`) and Ordered List (`<ol>`).
* **Images:** Embedded relief image (`<img>`) with `alt`, `width`.
* **HTML Table with Spans:**
  * **`rowspan="2"`:** Merges Medical Aid category across two centers.
  * **`colspan="2"`:** Merges Morning & Evening shift for 24-hour kitchen.
* **Multimedia:**
  * Audio player (`<audio controls>`) for emergency siren.
  * Video player (`<video controls>`) for disaster preparedness.
  * Embedded map (`<iframe>`).

### 2. Unit #2: Semantic Layout & Forms
* **Semantic Structure:** `<header>`, `<nav>`, `<main>`, `<section>`, `<aside>`, `<footer>`.
* **HTML Form (`<form>`):**
  * `<input type="text">` and `<input type="tel">` with `<label for="...">`.
  * Dropdown select menu (`<select>` and `<option>`).
  * Radio buttons grouped by `name="category"`.
  * Checkboxes for facility selection.
  * Multi-line text area (`<textarea>`).
  * Submit (`<input type="submit">`) and Reset (`<input type="reset">`) buttons.
* **Form Action:** Submitting opens `registered.html` displaying *"Registered Successfully"*.

### 3. Unit #3: CSS Styling
* **Universal Selector:** `* { margin: 0; padding: 0; box-sizing: border-box; }`
* **Element Selectors:** `body`, `h1`, `h2`, `table`, `th`, `td`.
* **ID & Class Selectors:** `#header`, `#nav`, `.container`, `.section`, `.highlight`.
* **Pseudo-Class (`:hover`):** Navigation links and table rows highlight on hover.
* **Attribute Selectors:** `input[type="text"]`, `input[type="submit"]`.
* **Text Styling:** `text-shadow: 2px 2px 4px black;`, `text-align: center;`.
